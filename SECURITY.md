# Security reporting

Please do not put access tokens, browser sessions, private PDF contents, SSH credentials, or personal environment files in public issues or logs. Use GitHub private vulnerability reporting when enabled; otherwise contact the repository owner through GitHub before sending sensitive details.

The current automatic acquisition adapter fetches public OA locations. Institutional credentials and automated sign-in are outside its scope. Keep the example model service bound to localhost, or protect a remote deployment using your own trusted network and access controls.

PDF parsers and model packages process untrusted documents. Use current supported dependencies and an isolated deployment appropriate to your environment. The project is a local CLI, not a public file-upload service.
