# 用 Codex 从论文检索做到跨论文比较

先确认 Codex 能搜索论文并展开命中页。通用包的服务器名称是 `journalflow`，如果组内已有服务器，使用组内给出的名称。[安装和首次检索](codex-mcp.md)

1. 复制两份模板到自己的项目目录，填写研究问题、纳入范围和索引版本。[逐篇证据表](templates/evidence-table.md) · [跨论文比较](templates/cross-paper-comparison.md)
2. 用几组简短关键词分别搜概念、数据来源和方法。记录每轮返回的片段数，按 DOI 归并结果。确认纳入哪些研究后，再展开摘要、数据与方法、结果和局限的具体页。通用包的关键词检索可以从两到四个英文词开始。
3. 在证据表里把论文概况和逐条证据分开填。读者应能从每条发现追到同一论文的原句和 PDF 物理页。表格、公式或数字有疑问时，打开原 PDF 对照。
4. 按比较模板核对样本、处理与对照、方法和结果变量。先判断可比性，再总结发现。把证据不足的地方列为待查项，并说明本次检索的范围。

可以在本机 Codex 对话中这样提问，将方括号内容换成自己的问题和路径。

> 用 [MCP 名称] 在 [期刊和年份] 查找关于 [研究问题] 的论文。先给出检索词和纳入的 DOI。展开每篇的关键 PDF 页，按 [证据表路径] 填数据、方法、结论、原文和页码。再按 [比较模板路径] 区分哪些结果能直接比较，哪些只能说明不同情境或方法。证据不足的字段标为待核对。

使用分享包的两页合成 PDF 试跑时，可以搜 `route disruption`，展开第 2 页，填一条证据。只有一个 DOI，跨论文比较应记录为「证据不足」，并说明还需要第二篇可比较的研究。
